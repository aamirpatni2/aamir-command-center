# Runtime agents

One folder per in-app agent: `prompt.md` (system prompt), `config.ts` (tools allow-list, model, max steps, output schema).
They're loaded by `packages/agents` from Milestone 3. The architecture is in `docs/AGENT_ARCHITECTURE.md`.

Planned: `orchestrator/`, `sales/`, `whatsapp/`, `content/`, `research/`, `student/`, `marketing/`, `analytics/`, `course/`.
